REGALO PARA MI NOVIA

Abrí index.html en el navegador o con Live Server de Visual Studio Code.

Las 10 fotos están divididas en dos galerías de 5 fotos. Las pantallas 6 y 7 tienen elementos inspirados en Coraline: puerta, llave, botones y noche estrellada.

Para publicarla, subí el contenido de esta carpeta a un repositorio de GitHub y activá GitHub Pages en Settings > Pages > Deploy from a branch. Después creá un QR con la URL pública.

IMPORTANTE: GitHub Pages es público; cualquiera con el enlace puede ver las fotos.

La tarjeta de Paredes es un marcador de posición; si conseguís una foto que tengas derecho a usar, se puede incorporar.
